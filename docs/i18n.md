# 中英文内容维护

## 覆盖范围

中文地址保持原样，英文站使用 `/en/` 前缀。当前 15 个系列的 93 篇主站文章都有英文版：56 篇教程、31 篇架构设计、6 篇系统设计案例。首页、三个频道、系列与文章页、搜索、关于、404 和课程目录共用组件及交互脚本，避免维护两套页面。

`/learning/` 与 `/en/learning/` 提供对应语言的课程介绍和筛选。独立课程正文、交互架构图继续由原 skill 流程维护，`public/learning/` 不在翻译范围内。英文目录在说明和每张卡片上标出中文课程，链接直接打开现有课程。

## 内容文件与身份

- 中文：`src/content/posts/tutorial/why-architecture-first.md`
- 英文：`src/content/posts/en/tutorial/why-architecture-first.md`
- 对应地址：`/tutorial/why-architecture-first/` 与 `/en/tutorial/why-architecture-first/`

路径均相对部署前缀；根路径和 GitHub Pages 子路径共用这套规则。英文频道路由包括 tutorial、templates 和 cases。

旧中文文件默认 `locale: zh-CN`，无需批量修改。中文默认翻译身份为 `频道/slug`，例如 `tutorial/why-architecture-first`。英文必须显式声明同样的 `translationKey`，用于语言切换和 hreflang 配对。

```yaml
locale: en
translationKey: tutorial/why-architecture-first
sourceHash: <核对译文时的中文文件 SHA-256>
series: foundations
order: 1
kind: tutorial
```

两种语言共享 series、order、kind；正文、标题、描述和标签使用各自语言。配对不依赖英文标题。改变既有中文 slug 时，应先显式保留原 translationKey，并处理旧 URL 兼容。

## 修改与新增译文

1. 同步编辑本站中文和英文文件，核对正文、表格、图中文字、Quiz 与决策卡。机器辅助翻译需要复核技术术语、数字、否定句和结论，不能用摘要代替原文。
2. 英文站内链接指向 `/en/...`；目标确实只有中文时，在链接文字中明确加 `(Chinese)`。局部锚点必须对应目标页面实际标题 ID。
3. 完成核对后，运行 `pnpm translation:hash tutorial/why-architecture-first.md`，将结果填写到英文 sourceHash。此命令只输出 hash，不修改文件，也不代表自动完成了翻译审查。
4. 运行 `pnpm validate`、`pnpm test`、`pnpm check`、`pnpm build`、`pnpm check:links` 和 `pnpm test:e2e`。

hash 对完整中文文件计算，统一将 CRLF 换成 LF。中文正文或元数据变化后，validate 会拦截未重新核对的译文；不要只更新 hash 来绕过内容审查。hash 和结构检查都不能证明翻译质量。

所有现有系列均已声明英文元数据，新增文章需要配套英文稿。新增系列时，在 `src/data/series.json` 加入 `translations.en.title`、`description`；精选系列另补 `featuredTags`。声明了英文元数据的系列必须完整配对。

## 界面文案与筛选

- `src/lib/i18n.mjs`：全站基础文案与共享页面的语言对应关系。
- `src/data/page-copy.ts`：首页、频道、关于与 404 文案。
- `src/data/series.json`：系列名称、描述和精选标签。
- `src/data/course-locales.ts`：课程介绍、方向、难度、形式与标签。

新增课程时同步补充英文目录元数据。筛选 URL 使用稳定的 track/tag ID，不随显示语言变化；语言切换保留查询参数，旧中文标签 URL 仍会规范化为 ID。

## 搜索、SEO 与评论

- 列表、上一篇/下一篇、相关推荐和 RSS 按语言过滤。
- Pagefind 根据 HTML lang 生成、加载对应语言索引；必须验证真实结果，不能仅翻译搜索框。
- 中英文页面分别输出 canonical，以及双向 hreflang 和中文 x-default。未来缺译内容保留明确提示，不生成占位英文页，也不跳到不相关的页面。
- `/rss.xml` 仅中文，`/en/rss.xml` 仅英文；搜索和 404 保持 noindex。
- giscus 界面随语言变化，继续按 pathname 映射，中英文文章各自拥有评论线程。

## 验证范围

`pnpm validate` 检查重复身份、缺失中文源稿、已发布系列缺译、频道/排序一致性、译文修订 hash、真实 Markdown H2/H3、插图与代码示例数量、Quiz/Decision 数量及中文链接标识。构建链接检查验证实际站内目标与锚点。

E2E 检查全部文章配对的生成结果与 SEO 对应关系、中英文首页结构、320–1440px 顶部导航尺寸、英文主题与 Quiz、同语言导航、搜索隔离、RSS、课程筛选及切换语言后的状态，以及无 JavaScript 导航。CI 在根路径和默认子路径两组运行。

## 英文稿来源

79 篇英文稿以原项目 study8677/awesome-architecture 的英文正文为基础，参考提交 `ed6505f`。对应中文正文与本站稿件经过比对：移除链接目标差异后正文一致；本轮补回四篇英文稿遗漏的 ADR 章节。其余 14 篇按本站当前中文稿翻译，包括认知韧性 3 篇和模型训练专题 11 篇；认知韧性的 3 张 SVG 提供配套英文文字版本。

稿件进入本站后，路由、元数据、交互组件和修订记录按本站规则维护，不依赖运行时翻译服务或重新同步上游。翻译时使用的临时工具及模型不进入应用依赖。
