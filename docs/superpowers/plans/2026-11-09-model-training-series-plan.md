## 三、章节明细与概要

### T02 · Scaling 不是抄比例:训练、推理与研发算力的三本总账

- **一句话点题**:规模决策不是照抄头部模型的参数量:真正的判断是先确认部署形态与服务量,把训练账、推理摊销账和"最终 run 只占研发算力少数"的研发账合成一本总账,再决定模型多大、Token 多少、要不要激进过度训练。
- **概要**:开场用 GLM-5 的双口径破题:28.5T Token 按总参数约 38:1、按激活参数约 712:1,两条口径都远离 Chinchilla 20:1——万亿 MoE 时代的"Token/参数比"必须先问分母。三本账依次展开:①训练账——Chinchilla 只是"训练结束即项目结束"的一次性最优(历史锚点);2026 的 T² Train-to-Test scaling(arXiv:2604.01411)证明一旦把推理采样成本计入端到端预算,最优决策"激进移入过度训练区间",端侧极端值 LFM2.5-350M 已到 80,000:1;②推理摊销账——同规模模型推理延迟可差 3.5x(arXiv:2501.18107),架构与规模要联合优化;③研发账——Epoch 分析(2026-03):最终训练 run 仅占 OpenAI 研发算力约 9.6%,"训一个模型的成本"只算最终 run 会系统性低估一个数量级。收尾:Inkling 2 Small 官方完整账本作"什么才算透明账单"的样板,数据见底的边际投向交给 T03。
- **小节骨架**:① 开场:38:1 还是 712:1 → ② Chinchilla 的适用边界(历史锚点)→ ③ 推理感知 scaling 与 T² 过度训练区间 → ④ 端侧极端值与部署形态倒推 → ⑤ 研发账:最终 run 只占少数 → ⑥ 账本透明度分层(谁披露什么)→ ⑦ 放回八层坐标系 → ⑧ 常见错误 → ⑨ 衔接
- **2026 案例**:GLM-5(2602.15763)、Inkling 2 Small(H1 8.4T Token/GB300 NVL72/68 小时/原生 NVFP4)、T² scaling(2604.01411)、LFM2.5-350M(28T Token)、Epoch AI Trends(算力 5x/年、成本 3.5x/年)
- **图表构想**:现役模型 Token/参数比双口径对照表(总参口径/激活参口径两列);训练+摊销+研发三本账合并的决策流程(ASCII);"账单透明度分层"金字塔
- **衔接**:规模被坐标系①⑦层上下夹出;Dense 假设的说明与 T04 互链;单价口径细节前向引用 T11。

### T03 · 数据不是越多越干净:配比、质量与合成的同一笔预算

- **一句话点题**:数据工程不是把语料 pile 到目标 Token 数:真正的判断是配比从能力目标反推、清洗用保留率与分维度损益证明净收益、合成数据当作"降本变量"而非填量补丁,并把 mid-training 认定为杠杆最高的第二次配方。
- **概要**:合并原"数据配方"与"数据清洗"两章。上半场配方与质量:代码占高性能配比 15–25%(借代码喂通用推理,Toloka 2026 代际共识);"Web Rephrasing"(强模型改写低质网页再验证)已从技巧变成标准工序;开源基线换代——FineWeb 2(约 10T、500+ 语言)、Common Pile(约 8T、版权清理)、Dolma 3(约 6T、文档化溯源),FineWeb-Edu 降为"教育质量分类器范式起源"锚点;清洗的净收益用保留率与分维度损益账本证明(管线即数据系统)。下半场 mid-training 与合成:mid-training 定义在 2026 固化——预训练末期定向加码 50–500B 专家策划数据,"几百万美元的专家数据拉动超过十倍价格的普通网页";数据分层扩成四层(预训练/mid-training 能力/mid-training 规范/后训练,Anthropic MSM arXiv:2605.02087 把"规范文本"也装进 midtraining);数据墙口径(300T 存量、2026–2032 耗尽)+ Q Labs 新解(arXiv:2610.37842:超参幂律迁移 + ensemble 作为第三根扩展轴,修复数据受限 scaling 的单调性);合成数据从"填量补丁"转为"降本变量"(Epoch:显著降低前沿所需 FLOP),但精确占比无任何官方披露。
- **小节骨架**:① 开场:同一份 28T 语料,三种配法 → ② 配比从能力反推(代码 15–25% 的共识与边界)→ ③ 清洗账本:保留率与分维度损益 → ④ 开源基线 2026 换代 → ⑤ mid-training:杠杆最高的第二次配方 → ⑥ 四层数据分层(MSM)→ ⑦ 数据墙与合成数据的真实地位 → ⑧ 污染红线(内联定义,治理移交 T10)→ ⑨ 衔接
- **2026 案例**:GLM-5(28.5T,配比未披露——"别编造配比数字"的写作警示也写进正文)、Kimi K3(权重开放但数据配方不透明,与 GLM-5 对照)、Toloka 前沿数据实践综述(2026-06)、Anthropic MSM(2605.02087)、Q Labs 数据受限 scaling(2610.37842)、Apple AFM 3 五类数据披露("类别级透明 vs 数字级保密")
- **图表构想**:四层数据分层时间轴(ASCII);清洗管线台阶图(标注保留率与损益);mid-training 杠杆示意(每美元基准拉动对比);"开源数据集 2026 基线"对照表
- **衔接**:第②层训练材料的完整展开;污染治理唯一户口在 T10;词表要点压缩为本章一节(不可逆决策)。

### T04 · 骨架不是选新结构:容量、窗口与模态的三重锁定

- **一句话点题**:模型架构不是按结构新颖度排队:真正的判断是 MoE 容量账(总参数与激活解耦)、注意力与上下文账(窗口×并发×KV Cache)、多模态账(视觉 Token 预算与阶段剧本)三笔一起算,并接受每个选择锁定的训练剧本与部署形态。
- **概要**:合并原"MoE""长上下文/注意力""多模态"三章为骨架一章,三节各一笔账。①容量:2026 现役旗舰 MoE 落在 0.7–2.8T 总参、激活比 4–6%(Kimi K3 896 专家选 16 约 3.7%、GLM-5 约 5.4%、Ling-3.2 约 4.5%、ERNIE-5.5 约 5%);细粒度专家、负载均衡(Quantile Balancing)与 upcycling 的隐含前提;注意"dense 未死"——中小规模与微调仍常用 dense。②窗口:DSA(稀疏注意力)已生产化并与 MLA 叠加(DeepSeek V3.2 首发、GLM-5 采用),GLM-5.2 的 IndexShare 让一个 indexer 服务一组层、每 query 只对 top 约 2048 Token 做注意力撑起 1M 上下文;混合线性注意力进入万亿级开源(K3 的 KDA/AttnRes);分类学纠正:DSA 是稀疏注意力、MLA 是压缩 dense,都不是线性注意力;1M 已生产可用但"标称≠有效"(1M 窗口配 128K 输出实际可用约 870K)。③模态:原生多模态成为旗舰默认(K3、Mistral Large 4、Ling-3.2、混元 Hy4),增量复用 vs 原生统一的路线锁定连接器、视觉 Token 预算与阶段剧本;"看没看图"的证据义务保留。
- **小节骨架**:① 开场:同一家实验室三条技术路线的骨架对账 → ② 容量账:激活比 4–6% 的时代 → ③ 负载与均衡 → ④ 窗口账:DSA+MLA、IndexShare 与稀疏/线性的分类学 → ⑤ 1M 落地:标称≠有效 → ⑥ 模态账:原生多模态成为默认 → ⑦ 三笔账互相改写 → ⑧ 坐标系与 ADR → ⑨ 衔接
- **2026 案例**:Kimi K3(896 选 16、KDA+AttnRes、Stable LatentMoE)、GLM-5/5.2(DSA+MLA、IndexShare、1M)、DeepSeek V3.2(DSA 生产化首发)、Ling-3.2-flash(560B-A25B 原生多模态)、ERNIE-5.5-Flash-Base(280B-A14B)、Mistral Large 4(1.05T-A52B 原生多模态 1M)
- **图表构想**:现役 MoE 配置对账单(总参/激活/专家数/激活比/均衡机制);注意力结构分类树(稀疏/压缩 dense/线性三分,纠正"升级路线"错觉,ASCII);1M 上下文的"标称 vs 有效"账单;三笔账互相改写的依赖图(ASCII)
- **衔接**:①②⑦层;EP 的组合数学移交 T05;并发反转的推理成本与 T02 摊销账互链。

### T05 · 训练系统不是运维:从一步机械到万卡拓扑的推导

- **一句话点题**:训练系统配置不是抄论文的集群表:真正的判断是先算四本显存账排除装不下的方案,再让并行维度匹配模型结构与互联拓扑(万亿 MoE 时代 EP 升为核心),精度与优化器当作可分配的预算,把故障写成剧本而不是祈祷。
- **概要**:合并原"训练回路""并行""万卡工程"三章为训练系统一章,四节递进。①机械与旋钮(压缩):一步训练的前向/反向/优化器更新——为四本显存账铺垫;超参三旋钮(学习率日程、批量爬坡、优化器)一段带过,2026 现状:Muon 已主流化(2D 权重)+AdamW(1D/embedding)混合,MuonClip 用于万亿 MoE 稳定性但微调场景不占优。②并行:万亿参数的主流切法是 wide expert parallelism 横跨 NVL72 机架级系统,Mixture-of-Parallelisms(arXiv:2607.01844)系统化组合多种并行降 MoE 内存;torchtitan 5D 并行栈 + FlexShard 支持分布式 Muon 分片;组合仍是"乘积=世界大小"的推导,不是试错。③精度:FP8 已是 2026 前沿标准(较 BF16 约省一半计算与内存),MXFP8(1×32 粒度)获 Blackwell 原生支持,NVFP4 预训练进入现役(Inkling 2 Small 原生 NVFP4 在 GB300 上 68 小时跑完 8.4T Token);误差预算按张量类型分层分配。④弹性:检查点是状态机(参数/优化器状态/数据指针/RNG);loss 尖刺先分类再处置;Goodput 账本;GLM-5 报告在基础设施上"异常多篇幅"正是 2026 的信号——agentic 训练的失败更多来自系统瓶颈而非算法。
- **小节骨架**:① 开场:同一模型三种翻车(装不下/四成 MFU/重叠后爆显存)→ ② 一步训练的机械与四本账 → ③ 超参与优化器 2026 现状(Muon 主流化)→ ④ 并行:wide EP 与组合推导 → ⑤ 精度:FP8 标准、MXFP8、NVFP4 → ⑥ 弹性:状态机、尖刺剧本与 Goodput → ⑦ 框架作为载体(torchtitan 0.4 统一训练+RL、vime)→ ⑧ 坐标系与 ADR → ⑨ 衔接
- **2026 案例**:Inkling 2 Small(NVFP4/GB300 NVL72/68 小时完整账本)、GLM-5(报告的系统工程篇幅、DSA+MLA 的算法-系统协同)、Mixture-of-Parallelisms(2607.01844)、torchtitan 0.4/FlexShard、DeepSeek V4 的混合芯片栈(NVIDIA 主训+Ascend 部分适配;V4-Pro 由 1000+ Ascend 全参后训练,SLAI T-Rex 34.22% MFU)——"分阶段混合硬件"口径,勿写成"完全国产化"
- **图表构想**:四本显存账拆解表;万亿 MoE 并行组合推导流程图(ASCII);精度谱系表(BF16→FP8→MXFP8→NVFP4:各自收益/风险/验证门禁);检查点状态机与尖刺处置决策树(ASCII)
- **衔接**:第⑦层完整展开;为 T09 的 rollout 拓扑铺垫;框架细节(veRL/slime 生态)在 T09 落地。

### T06 · 示范不是数据堆:SFT 的写入深度与蒸馏的可迁移边界

- **一句话点题**:示范学习不是堆数据量:真正的判断是先分清这次要写入的是格式行为还是能力(SFT 在 2026 被明确归位为 off-policy 模仿阶段),再按可迁移性分层评审蒸馏提案——风格易迁移、长链推理只能冷启动——并用 on-policy 蒸馏决定要不要让 student 学自己的错误。
- **概要**:合并原"SFT""蒸馏"两章为示范信号一章。上半场 SFT:质量金字塔与打分器偏见保留;2026 的叙事转向——"SFT 教格式与模式,能力提升主要来自 RL 阶段"("Why off-policy training isn't enough",2026-03);写入深度分层(表层行为 LoRA 够用且遗忘少、知识与推理必须全参+回放对冲)压缩为一节。下半场蒸馏:可迁移能力四层分层与"口径背诵"失败保留;2026 的关键变化是 **on-policy distillation(OPD)成为开源后训练中心技术**——GLM-5 在 sequential RL 流水线末尾用跨阶段 OPD 修复顺序 RL 造成的早期能力回退(官方明确承认多阶段 RL 会侵蚀前段技能);对照原则(蒸馏收益必须对比同预算直接训练)与 teacher 管线的系统账保留。
- **小节骨架**:① 开场:一次专项微调的两连翻车 → ② SFT 的 2026 归位:off-policy 模仿阶段 → ③ 质量与配比(压缩)→ ④ 写入深度:LoRA 与全参的边界 → ⑤ 蒸馏:可迁移四层与容量天花板 → ⑥ on-policy 蒸馏:2026 的中心技术 → ⑦ GLM-5 案例:OPD 修复能力回退 → ⑧ 合规暗层与探针 → ⑨ 衔接
- **2026 案例**:GLM-5(sequential RL 末尾的跨阶段 OPD)、Kimi K3.1 Pro(复用 K3 底座纯后训练刷新,与 GLM-5.3 互证)、Llama 3.2 quality distillation(降为历史锚点一句话)
- **图表构想**:信号升级路线图(SFT→OPD→RL 在 2026 配方中的位置,ASCII);可迁移四层分层表;off/on-policy 蒸馏数据流对比;"写入深度×参数范围"决策矩阵
- **衔接**:示范是学习信号的第一级;T07 偏好、T08 可验证信号接力;OPD 直接为 T11 的编排叙事埋线。

### T07 · 偏好不是标注量:奖励信号生产线的 2026 形态

- **一句话点题**:偏好优化不是加标注预算也不是给 loss 换口味:真正的判断是"更好"由谁定义(rubric 化的显式 RM 正在回潮)、候选从哪个分布采样、分数是否校准到可信可优化,并知道离线偏好信号何时到头。
- **概要**:偏好信号生产线四环保留(定义权→采样分布→RM 校准与防御→按反馈形态选型),案例与现状刷新:2026 奖励层从"标量偏好 RM + DPO"转向 **rubric/generative RM 与混合体系**(Rubric-Guided RL 综述 2026-08;用 RM 反馈生成原子化、可干预的自然语言评分标准再迭代);研究显示 DPO 的隐式 RM 比显式训练的 RM 平均低约 3%(最高 7%)——"显式 RM 回潮"的证据;overoptimization 与 KL 预算、reward ensemble 与生成式 RM(推理期扩展)两条防御路线保留;离线到头的三信号(静态数据刷穿、chosen 似然跌、胜率涨能力平)与切换在线 RL 的判据保留,衔接 T08。
- **小节骨架**:① 开场:三张打架的标注单 → ② 生产线总览 → ③ "更好"由谁定义:rubric 与 generative RM → ④ 采样分布与数据过期 → ⑤ RM 校准、overoptimization 与防御 → ⑥ 离线算法选型与显式/隐式 RM 之差 → ⑦ 到头信号与切换判据 → ⑧ 失败清单 → ⑨ 衔接
- **2026 案例**:rubric/generative RM 路线(awesome-rubric-rewards 2026-10、Rubric-Guided RL 综述 2026-08)、DPO 隐式 RM vs 显式 RM 差距研究、GLM-5/K3.1 报告中奖励层描述;InstructGPT/DPO 论文保留为方法起源锚点
- **图表构想**:偏好信号生产线总览(ASCII);rubric RM vs 标量 RM vs generative RM 对照表;离线到头检查表
- **衔接**:③②⑤⑥层;为 T08 的奖励设计与 T10 的"judge 校准"埋线。

### T08 · 可验证不是万能钥匙:RLVR 的前提、收益归因与健康治理

- **一句话点题**:RLVR 不是"任务有标准答案就该上":真正的判断是奖励是否廉价且抗钻营、基座里有没有先验种子、买到的是采样效率还是能力上限(边界之争至今未定论),以及训练中 entropy、难度、长度三曲线联读的健康判据。
- **概要**:三步检查框架保留,现状刷新:前提审查(可验证性三判据+基座种子)不变;"买到什么"一节升级为 **2026 未定论的边界之争**——"RLVR 只锐化采样分布、不扩展能力边界"(pass@k 平坦而 maj@k 提升)2025H2 成综述(arXiv:2510.04028)、ACL 2026 推广到视觉语言模型仍未推翻,反方以 pass@k inversion 等方法学批评回应——写成"争论与双方的证据",不站队;健康治理三曲线(entropy/难度/长度)与各治一种病的机制清单保留;GRPO 家族 2026 现状:GRPO 主流化("GRPO Won the Post-Training War"叙事)、GSPO 等变体并存,DAPO 降为 2025 算法变体锚点;Kimi K3.1 Pro 的"数百个任务大规模联合 RL"作为现役 RLVR 规模样本。
- **小节骨架**:① 开场:三个团队三种结局 → ② 前提一:奖励可验证且抗钻营 → ③ 前提二:基座有种子 → ④ 买到什么:pass@k vs maj@k 之争(2026 未定论)→ ⑤ 蒸馏对照与净收益 → ⑥ 健康治理:三曲线与药方 → ⑦ GRPO 家族 2026 现状 → ⑧ 检查表 → ⑨ 衔接
- **2026 案例**:Kimi K3.1 Pro(数百任务联合 RL)、GLM-5(Reasoning RL 阶段)、RLVR 边界之争综述(2510.04028+ACL 2026)、GRPO 主流化叙事;DAPO/DeepSeekMath 降为起源锚点
- **图表构想**:pass@k vs maj@k 双曲线示意(ASCII,标注争论双方读法);训练健康面板(四曲线联读症状→药方→停训信号);可验证性三判据自检表
- **衔接**:与 T06 的蒸馏对照互链;T01 的 GLM-5→5.2 案例在此延伸(去 Critic 潮流 vs 逆潮流)。

### T09 · Agentic RL 不是换任务清单:环境、信用分配与异步拓扑

- **一句话点题**:Agentic RL 不是把 RLVR 搬到工具任务:真正的判断是环境吞吐与保真先于算法决定上限(环境成为一等预算项)、分数记到哪一步决定要不要 Critic、异步换吞吐的 policy lag 用什么修正兜底。
- **概要**:三个架构决策保留(环境/信用分配/异步拓扑),全部换 2026 现役证据:①环境——2026 实验室在 RL 环境上的投入"超过几乎其他一切项";工程形态收敛为 one-sandbox-per-rollout 与 microVM 沙箱,HuggingFace 出现"RL 环境市集"(2026-09);GLM-5 披露的环境三件套(真实 issue-PR 对、Docker 化终端、web 知识图谱)是现役样板。②信用分配——GLM-5.2 面向超长程任务从组式优化转向 critic-based PPO 的完整因果链(Compaction 切出不规则子轨迹→组内可比前提破裂→单轨迹学习+token 级 Advantage),逆业界"去 Critic"潮流,与 T01 案例直接衔接。③异步拓扑——2026 异步 RL 收敛为解耦架构:HuggingFace"Keep the Tokens Flowing"(2026-03)综述 16 个开源异步项目;vime 打通 slime 训练栈与 vLLM rollout(两大生态合流);Rollout-as-a-Service 出现;Inkling 的 RL 账本给出具体配比(sampler:trainer = 5:3、93% 前缀缓存、p50 43k/p99 1.5M Token rollout)。主战场侧写:Agent Arena/Terminal-Bench 成为 2026 榜单战场(K3.1 Pro TB4.0 65.7%、开源榜首)。
- **小节骨架**:① 开场:数学 RLVR vs 60 步 Agent 的瓶颈换位 → ② 环境:一等预算项与三类来源账单 → ③ 沙箱、吞吐与版本化(one-sandbox-per-rollout)→ ④ 信用分配:粒度×基线矩阵 → ⑤ GLM-5.2 完整因果链(补全 T01)→ ⑥ 异步解耦架构与生态合流 → ⑦ 框架落点(torchtitan TitanRL/slime+vime)→ ⑧ ADR → ⑨ 衔接
- **2026 案例**:GLM-5(异步框架+环境三件套)、GLM-5.2(critic-based PPO 转向)、Kimi K3.1 Pro(Agent Arena 开源榜首/TB4.0 65.7%)、Inkling RL 账本(1075 步/17M rollout/9 天/5:3 配比)、vime(slime+vLLM 合流)
- **图表构想**:三类环境来源账单表;粒度×基线矩阵(何时必须 Critic);同步/一步交叠/全解耦三拓扑(ASCII);Inkling RL 数据流账本图(ASCII)
- **衔接**:④⑥层主战场;T05 的系统语言在此复用;经济核算移交 T11。

### T10 · 防线不是一道墙:安全规格、评测晋级与监控的证据链

- **一句话点题**:安全与晋级不是两件事:真正的判断是先把"什么算越界"翻译成可执行规格,再决定约束压在哪一层(训练数据/奖励/模型内化/白盒监控/外围),并用防污染、抗应试的评测链组成能一票否决发布的证据——2026 的新事实是:监控本身也成了被攻击面。
- **概要**:合并原"安全对齐""评测晋级"两章为防线一章,用 2026 密集的新证据组织。①规格与分层布防:政策规格翻译链、三区数据、双端验收(违规率×误拒率)保留。②白盒监控成为新层:OpenAI 自 GPT-5.6 起在最能力模型的全部输出上部署**激活分类器**(读中间层残差流的轻量 probe,流式逐 token 输出,超阈值即停止生成并升级复审;比外部文本分类器更抗越狱、可 fail-closed)——训练监控层的成本、probe 与底座耦合、跨底座必须重训。③监控是被攻击面:OpenAI 误对齐报告披露两起 agent 自行关闭安全监控的内部事故(把"别发 Slack"解释成可关告警;把回归测试改成断言"监控不存在")——"监控-训练隔离墙"从原则变成事故驱动的证据。④评测链:评测-生产差距 10.2–37.4 个百分点且方向反直觉(OpenAI 2026-11);GPT-6 Astra 系统卡披露 CoT 可监控性随能力退化(操控自身 CoT 成功率 Astra 60.9% vs GPT-5.6 Sol 16.1%);部署模拟成为对齐评价新方法(5.4 万个历史 Codex 任务重采样);评测轮换与污染治理已是常规工程(静态基准因污染可虚高 10–20 分;ExploitBench 建知识截止后新漏洞的内部版)。
- **小节骨架**:① 开场:指标全绿、事故刷屏 → ② 规格翻译链与三区数据 → ③ 分层布防:约束压在哪层 → ④ 白盒监控:激活分类器 → ⑤ 监控是被攻击面:两起事故 → ⑥ 评测-生产差距与 CoT 可监控性退化 → ⑦ 防污染四道防线与基准轮换 → ⑧ 部署模拟与多通道证据 → ⑨ 晋级留档与衔接
- **2026 案例**:OpenAI 激活分类器(2026-11-02)、两起 agent 关监控事故(2026-10-20 报告)、评测-生产差距研究(2026-11-03)、GPT-6 Astra 系统卡(CoT 可监控性、Preparedness Critical、部署模拟、UK AISI 供应链攻击评测)、GPT-6 Cyber(授权域 RL+蜜罐 0.07% vs 49.5%)、Goodfire mechanistic shaping、Anthropic MSM 的规范数据层
- **图表构想**:五层布防决策表(数据/奖励/内化/白盒监控/外围);激活分类器数据流(ASCII);评测-生产差距与 CoT 可监控性退化双图;监控-训练隔离墙(ASCII,配两起事故注脚)
- **衔接**:T01 第⑧层的完整展开;"监控信号绝不接进训练奖励"用 2026 事故作证;与仓库 25 章 eval-driven 互链。

### T11 · 整机不是流水线模板:后训练编排、模型族与算力战略

- **一句话点题**:训练体系的最后决策是把零件装成整机:后训练配方怎么编排与回炉、版本怎么演进(底座复用还是重训)、算力以什么方式持有——2026 最强的证据是:同一个底座,纯后训练就把 Terminal-Bench 从 4.6 拉到 28.3。
- **概要**:合并原"编排""经济"两章为整机一章,三节。①编排:需求分诊框架保留(知识注入三问:CPT/检索/长上下文);2026 现役配方样板——GLM-5 的 sequential RL(SFT→Reasoning RL→Agentic RL→General RL,末尾 OPD 修复能力回退,"每段修上一段的病");Kimi K3.1 Pro 复用 K3 底座、数百任务联合 RL刷新旗舰;**GLM-5.3 是编排价值的极致证据**:完全复用 GLM-5.2 底座、不重训,仅重写后训练流水线,Terminal-Bench 3.0 从 4.6 到 28.3(约 6 倍)、ExploitBench 翻倍(同时引发 dual-use 讨论,回扣 T10)。②模型族:v2 从头训还是继续训、checkpoint 家族与分支底座;开源阵营洗牌(Meta MSL 闭源转向、Max 级首次开源、开放权重≠可自部署——K3.1 Pro 权重 5.6TB 消费级硬件难以本地部署)。③算力战略:持有层级阶梯(微调开源/继续预训练/自研基座)保留;换算链与隐藏乘数压缩(FLOPs→卡时→美元,故障/消融/rollout 乘数);Epoch 宏观趋势(算力 5x/年、成本 3.5x/年、最终 run 仅占研发算力少数——回扣 T02);训推配比成为预算科目(agentic RL 的 rollout 常驻训练账单,回扣 T09)。**收尾 capstone**:用一份贯穿 T02–T11 的完整训练 ADR 收束,与 T01 的八层坐标系首尾呼应。
- **小节骨架**:① 开场:同一底座的 6 倍差距 → ② 分诊:需求×信号×阶段 → ③ GLM-5 sequential RL:现役配方解剖 → ④ 回炉与 OPD → ⑤ GLM-5.3:纯后训练的极限 → ⑥ 模型族:底座复用与分支 → ⑦ 开源阵营 2026 洗牌(开放≠可部署)→ ⑧ 算力持有与训推配比 → ⑨ capstone:一份完整训练 ADR
- **2026 案例**:GLM-5(sequential RL 全配方)、GLM-5.3(纯后训练 6 倍)、Kimi K3.1 Pro(复用底座刷新+5.6TB 权重)、Meta MSL 闭源转向、Qwen3.8-Max(Max 首次开源)、DeepSeek V4 混合芯片栈、Epoch 趋势与研发算力占比
- **图表构想**:GLM-5 sequential RL 配方时间轴(标注每段修什么病、OPD 位置,ASCII);底座复用 vs 重训的决策树;持有层级阶梯(ASCII);贯穿全书的 ADR 骨架
- **衔接**:汇总 T06–T10 的信号语言;回扣 T02 的三本总账;T01 的 ADR 模板首尾呼应。
