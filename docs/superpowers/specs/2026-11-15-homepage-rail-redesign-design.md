# 主页导览重设计（四站轨道）— 设计记录

- 日期：2026-11-15
- 状态：已与站长对齐定稿（原型交互稿 v5，存于 `.superpowers/brainstorm/506-1794730986/content/hifi-v5-motion.html`）
- 目标：新访客 5 秒内能对号入座——看懂四个功能入口分别适合谁、什么场景用。

## 背景

旧首页 hero 下方只有 3 张抽象文案入口卡（入门教程/架构地图/系统设计），「项目学习」缺席；文案（"建立思考系统的方式""从真实约束走向取舍"）对新人没有指引性。且「入门教程」渠道实际含 9 个系列（进阶/实战/AI 专题均在其下），名不副实。

## 定稿决策（按对齐顺序）

1. **导览形态**：四站轨道图（方向 B 视觉），语义为**平行入口、按需求选门**——一条轨道、四个站点、不强调先后。
2. **全局改名**：「入门教程」→「系列教程」；「架构地图」→「架构设计」。URL（`/tutorial/`、`/templates/`）与系列内部标题（入门篇/进阶篇…）不动。改名覆盖：导航标签、面包屑、频道页标题、RSS/about 描述。
3. **首屏 = 一张导览大屏**：hero 面板内上半为标题区（标语 + "不知道从哪开始？四个方向并行，按你的需求选一个入口，随时换道。"），下半为四站轨道。原双 CTA 与右侧"书"装饰删除。
4. **首页导航栏**：不展示四个入口链接，只留品牌 + 加长搜索框 + 主题切换。子页面导航保持原样（内页保留入口曝光）。
5. **首页结构**：导览大屏 → 编辑精选（2 张卡）→ 最近更新。删除「按系列阅读」「走进真实项目」区块（职责由轨道 + 频道页承接）。
6. **编辑精选数据源**：`series.json` 条目加 `featured` / `featuredNote`（可选 `href` 直链），手工策展。首发精选：基础模型训练决策专题、AI 时代的人类自我保护。
7. **动效**（纯 CSS + 少量 JS）：搜索聚焦展开（380→440px）+ ⌘K 聚焦；站点卡悬停上浮/边框亮紫/轨道点发光/箭头滑出；精选卡与最近更新行同类悬停；主题钮悬停旋转；进场依次上浮淡入；标题圆点呼吸；轨道线 shimmer。

## 四站文案（定稿）

| # | 站点 | 适合 | 得到什么 | 徽章 |
|---|------|------|---------|------|
| 01 | 系列教程 | 想系统学架构的人 | 9 个系列由浅入深，从架构思维一路读到 AI 时代的工程判断。 | 56 篇 |
| 02 | 架构设计 | 想看懂真实系统的人 | 看别人怎么设计：电商、支付、Claude Code 等真实系统的组织结构。 | 31 张 |
| 03 | 系统设计 | 正在做设计决策的人 | 学自己怎么设计：6 个案例，从真实约束走到取舍的完整推理。 | 6 个 |
| 04 | 项目学习 | 想跟着源码实战的人 | 沿真实项目的源码走一遍，把架构理解再往深推一层。 | 3 门 |

> 边界句式：架构设计 = "看别人怎么设计"（消费现成架构）；系统设计 = "学自己怎么设计"（训练设计能力）。

## 改动范围（实现侧）

- `src/pages/index.astro`：重写（hero+rail / featured / recent）
- `src/components/Masthead.astro`：首页隐藏导航链接（按路径判断）；搜索框加长 + 占位文案
- `src/scripts/navigation.ts`：补 ⌘K 聚焦搜索
- `src/styles/global.css`：轨道、精选卡、动效样式
- `src/data/series.json` / `series.ts`：featured 字段 + 渠道改名
- `SeriesPage.astro` / `PostPage.astro` / `tutorial/index.astro` / `templates/index.astro` / `cases/index.astro` / `about.astro` / `rss.xml.ts`：改名连带
- `tests/e2e/smoke.spec.ts`：导航断言调整（首页无导航链接后改为子页面断言或轨道卡断言）

## 非目标

- 不改 URL 结构、不迁移内容、不改子页面布局
- 不做真实站内即时搜索（保持现有 /search/ 页，只改入口形态）
